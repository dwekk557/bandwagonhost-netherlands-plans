## 荷兰机房实测数据参考

公开测评里这台机器表现不错，但有个细节很多转载没讲清：测试用的是官方提供的 SPECIAL 160G 高配机型（6 核 CPU、8GB 内存、160GB SSD、5000G 月流量），而限量版套餐本身是 1 核 / 1GB。所以 CPU 和磁盘成绩不能直接套到 $39 套餐上，同节点的网络数据参考价值更高。

硬件方面，节点用 AMD EPYC Genoa 处理器，磁盘 4K 随机读写约 210 MB/s、IOPS 5.2 万以上，1M 顺序读写 3.3–3.6 GB/s，跑网站和数据库没什么压力。

网络方面（iperf3 实测）：阿姆斯特丹本地约 9.2 Gbps，伦敦约 6.4 Gbps，纽约约 2 Gbps，洛杉矶 640–850 Mbps。欧洲各地连接普遍在 1 Gbps 以上，去北美和亚洲其他地区基本几百兆的水平。注意限量版套餐端口限速 2.5 Gbps，以上数字反映的是节点和上游的能力。

IP 质量对做流媒体和 AI 工具的人比较关键，这批 IP 的表现：Netflix 完整解锁（识别为荷兰，支持非自制剧），YouTube 走阿姆斯特丹缓存节点，Disney+、ChatGPT、Claude、TikTok、Spotify、Steam 都能正常解锁；Gemini 和 Meta AI 不行。
